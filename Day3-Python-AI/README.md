# Day 3 - Student Performance Analysis

## Objective

Analyze a student performance dataset using Python, Pandas, and Matplotlib.

## Features

- Load a CSV dataset
- Display dataset information
- Calculate average scores
- Find highest and lowest scoring students
- Identify students with attendance below 75%
- Identify students at risk of failing
- Calculate average score by course
- Analyze the relationship between attendance and final score
- Handle missing or invalid values
- Generate visualizations

## Technologies Used

- Python
- Pandas
- Matplotlib

## Files

- `dataset.csv` – Student dataset
- `main.py` – Analysis code
- `requirements.txt` – Required libraries
- `conclusion.md` – Findings
- `charts/` – Generated charts

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the program:

```bash
python main.py
```

The program will analyze the dataset and generate charts in the project folder.
