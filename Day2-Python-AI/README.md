# Day 2 - Student Data Analysis

## Objective

This project demonstrates basic Python programming and data handling using Pandas.

## Features

- Store student information using Python dictionaries and lists
- Convert data into a Pandas DataFrame
- Display all student records
- Filter students with marks above 70
- Calculate average marks
- Find the student with the highest marks
- Find the student with the lowest marks
- Display the total number of students

## Technologies Used

- Python 3
- Pandas

## How to Run

Install Pandas:

```bash
pip install pandas
```

Run the program:

```bash
python main.py
```
