# Day 4 – Student Performance Prediction

## Objective

The objective of this project is to build a simple Machine Learning model that predicts whether a student will **Pass** or **Fail** based on academic performance.

---

## Problem Solved

Predict whether a student is likely to pass using historical student performance data.

---

## Features Used

- Attendance
- Assignment Score
- Midterm Score
- Final Score

---

## Target Variable

- Pass = 1
- Fail = 0

---

## Machine Learning Model

Logistic Regression

---

## Evaluation Metrics

- Accuracy
- Confusion Matrix
- Classification Report

---

## Visualizations

- Confusion Matrix
- Prediction Distribution

---

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib

---

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python main.py
```

---

## What I Learned

- Loading datasets with Pandas
- Data preprocessing and cleaning
- Creating target labels
- Splitting data into training and testing sets
- Training a Logistic Regression model
- Making predictions
- Evaluating model performance using accuracy, confusion matrix, and classification report
- Visualizing machine learning results
